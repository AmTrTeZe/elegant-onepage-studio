# Bain Consulting Showcase

Je veux créer un site onepage. Je vous upload tous les écrans de mon site de l'écran d'arriver sur le site jusqu'au formuaire qui est la dernière section de ce site onepage. Je vous upload aussi l'explication de toutes les typos.
Je veux des effets de mise en place des typos des textes qui soient élégants. C'est un site qui est pour un cabinet conseil type Bain
